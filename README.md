# 🦷 TimeGold — Sistema de Gestão Odontológica

TimeGold é uma plataforma moderna para o agendamento e gestão de atendimentos em clínicas odontológicas.
Desenvolvida com foco em eficiência, design intuitivo e integração entre profissionais e pacientes, a solução facilita a rotina de administradores, dentistas e recepcionistas.

# 🌟 Principais Recursos

🗓️ Agenda inteligente — visualize e organize atendimentos com clareza.

👩‍💼 Painel administrativo — gerenciamento de profissionais e tarefas.

💬 Integração com WhatsApp — comunicação direta com pacientes.

🪄 Interface moderna — design com gradiente roxo e layout responsivo.

🔐 Acesso seguro — login diferenciado para administradores e profissionais.

# 🖥️ Tecnologias Utilizadas

- Vue.js 3 (Composition API)

- Tailwind CSS para o design responsivo e estilização moderna

- PrimeVue (componentes interativos e visuais)

- JavaScript / HTML / CSS

- Font Awesome / Bootstrap Icons

# 🚀 Como Executar o Projeto

- Clone o repositório
git clone https://github.com/maisamarall/TimeGold.git

- Acesse a pasta do projeto
cd timegold

- Instale as dependências
npm install

- Rode o projeto localmente
npm run dev
